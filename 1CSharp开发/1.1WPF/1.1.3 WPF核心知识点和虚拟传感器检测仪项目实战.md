# WPF核心知识点
## 1.基建
### 知识点1：布局(XAML与布局)
- Grid(万能布局)和StackPanel(线性布局)

###  知识点2:依赖属性(DP)与路由事件
- 依赖属性:背后是全局字典，只有被赋值时才占用内存，天然支持数据绑定和动画。
	- .NET属性背后是一个私有字段。
- 路由事件:在“视觉树”上冒泡(自底向上)或隧道(自顶向下，带Preview前缀)传播。
	- 传统事件只能由订阅者触发。
## 2.机制
### 知识点3:数据绑定
- Data Binding：理解DataContext(数据上下文)，UI和数据模型相连，UI自动更新。
- INotifyPropertyChanged：连接逻辑层和UI层的桥梁。
- MVVM:将交互封装为Command(命令),将数据封装为ViewModel。
	- 主流MVVM框架:CommunityToolkit.Mvvm(微软官方推荐，轻量)；Prism(大型企业级应用)

## 3.外观(样式与模板)
- Style与触发器(Triggers):根据属性变化(如鼠标悬浮IsMouseOver)动态改变外观；
- DataTemplate(数据模板):渲染数据；
- ControlTemplate(控件模板):无外观，有逻辑和动作。

## 4.性能与多线程
- 1.Dispatcher：WPF规定，谁创建了UI元素，谁才能修改它。后台线程计算完数据后，必须通过 `Application.Current.Dispatcher.Invoke()` 扔回UI线程更新，否则会报错。
2. UI虚拟化：当你需要在 `DataGrid` 或 `ListBox` 中展示10万条数据时，必须开启 `VirtualizingStackPanel`，否则内存会爆且卡死。它只渲染屏幕可见的几十条数据的UI元素。

### 2.2数据库上下文:AppDbContext.cs

```Csharp
using System;
using System.Collections.Generic;
using System.Text;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Options;//ORM对象关系映射框架，支持SQL Server、SQLite、PostgreSQL等数据库,让.NET对象与数据库交互，无需编写大量数据访问代码。

namespace SensorMonitorPro
{
    public class AppDbContext : DbContext
    { //DbContext负责与数据库的连接和操作，提供了对数据库的增删改查等功能。数据库对话。
        //定义数据表
        //DbSet表示一个实体集合，代表数据库中的一张表。通过DbSet可以对表进行增删改查操作。
        public DbSet<SensorRecord> SensorRecords { get; set; }

        /*配置VS自带的本地SQL Server引擎(LocalDB)
         重写DbContext的OnConfiguring方法
        optionBuilder是配置构建器，用来设置提供程序(SQL Server,SQLLite)和连接字符串等。
        protected:受保护，只能在继承体系中访问
         */
        protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
        {
            string connectionString = @"Server=(localdb)\MSSQLocalDB;Database=SensorMonitorPro;Trusted_Connection=True;TrustServerCertificate=True;";
            optionsBuilder.UseSqlServer(connectionString);//指定使用SQL Server作为数据库提供程序，并传入连接字符串。        
        }
    }
}
```
