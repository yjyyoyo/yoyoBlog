# 一、引用
## System

```Csharp
using System;//命名控件
```

- **基础数据类型**：`Int32` (即 `int`)、`String`、`Boolean`、`DateTime`、`Double` 等
- **控制台交互**：`Console` (WriteLine, ReadLine 等)
- **数学计算**：`Math` (Abs, Sqrt 等)、`Random`
- **异常与核心类**：`Exception`、`Object`、`Array`、`GC`
- **常用工具**：`Convert`、`StringComparer`、`Uri`

## Collections.Generic
```Csharp
using System.Collections.Generic;//泛型集合，创建和操作强类型的列表、字典等数据结构
```

- **列表**：`List<T>` – 动态数组   
- **字典**：`Dictionary<TKey, TValue>` – 键值对映射
- **集合**：`HashSet<T>` – 无序不重复集合
- **队列/栈**：`Queue<T>`、`Stack<T>`
- **其他接口**：`IEnumerable<T>`、`IList<T>`、`ICollection<T>` 等

```csharp
List<string> names = new List<string>();
Dictionary<int, string> map = new Dictionary<int, string>();
```

## Text
```csharp
using System.Text;//高效字符构建和字符编码处理
```

- **StringBuilder**：可变的字符串构造器，频繁拼接字符串时比 `+` 性能高很多
- **Encoding**：字符编码处理（如 UTF-8、ASCII 转换）  
    常用子类：`Encoding.UTF8`、`Encoding.ASCII`、`Encoding.Unicode`
- 其它较少直接使用的类：`Decoder`、`Encoder` 等
```csharp
StringBuilder sb = new StringBuilder();
sb.Append("Hello");
sb.Append(" World");
string result = sb.ToString();

byte[] utf8Bytes = Encoding.UTF8.GetBytes("你好");
```
