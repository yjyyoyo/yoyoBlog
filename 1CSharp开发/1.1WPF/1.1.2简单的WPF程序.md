# 在VS的Solution Explorer中，Solution下的Project有3种类型：
1. **Class Library（类库）** - 生成可重用的 DLL 程序集，供其他项目引用，没有独立的可执行入口。
2. **Console Application（控制台应用程序）** - 生成命令行可执行文件（.exe），通过控制台窗口与用户交互。
3. **Windows Forms / WPF Application（Windows 窗体 / WPF 应用程序）** - 生成带有图形用户界面（GUI）的可执行文件，基于 Windows Forms 或 WPF 框架。

# 项目结构
- XAML+C#代码隐藏的分离模式。将界面设计与业务逻辑分离。
- 结构
	- .xaml：UI界面(声明式)
	- .xaml.cs:逻辑代码(命令式)
	- App.xaml：应用程序级配置和资源
	- AssemblyInfo.cs:程序集元数据
![[Pasted image 20260722161226.png|359]]
- 结构
	- 解决方案Solution:包含多个项目    
		- .sln:管理项目之间的引用关系和构建设置。
	- 项目Project
		- .csproj，WPF应用程序，编译后生成.exe
	- 依赖项References:显示项目所引用的外部库和NuGet包。
		- .NET SDK的核心引用
	- App.xaml:WPF应用程序的入口文件，等价于WinForms中的Program.cs。
		- App.xaml.cs (App.xaml的代码隐藏文件，包含一个App类，继承自Application。)
			- 应用程序的启动/退出的事件处理；全局异常处理；依赖注入的初始化。
	- AssemblyInfo.cs:程序集级别的元数据属性(版本号;信息;COM可见性设置)
	- MainWindow.xaml:主窗口的界面定义文件(UI和逻辑分离)
		- 用XAML描述窗口的布局、控件、样式等。
		- 默认包含窗口的基本属性和Grid等布局容器。
	- MainWindow.xaml.cs:xaml的代码隐藏文件
		- 包含MainWindow类，继承自Window。
		- 包含窗口的事件处理、与界面交互的业务逻辑；数据绑定相关的代码。
