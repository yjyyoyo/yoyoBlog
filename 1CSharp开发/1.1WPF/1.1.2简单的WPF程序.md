# 在VS的Solution Explorer中，Solution下的Project有3种类型：
1. **Class Library（类库）** - 生成可重用的 DLL 程序集，供其他项目引用，没有独立的可执行入口。
2. **Console Application（控制台应用程序）** - 生成命令行可执行文件（.exe），通过控制台窗口与用户交互。
3. **Windows Forms / WPF Application（Windows 窗体 / WPF 应用程序）** - 生成带有图形用户界面（GUI）的可执行文件，基于 Windows Forms 或 WPF 框架。
