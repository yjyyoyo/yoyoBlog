# 在VS的Solution Explorer中，Solution下的Project有3种类型：
1. **Class Library（类库）** - 生成可重用的 DLL 程序集，供其他项目引用，没有独立的可执行入口。
2. **Console Application（控制台应用程序）** - 生成命令行可执行文件（.exe），通过控制台窗口与用户交互。
3. **Windows Forms / WPF Application（Windows 窗体 / WPF 应用程序）** - 生成带有图形用户界面（GUI）的可执行文件，基于 Windows Forms 或 WPF 框架。

# 项目结构
- XAML+C#代码隐藏的分离模式。将界面设计与业务逻辑分离。
- 结构
	- .xaml：UI界面(声明式)
	- .xaml.cs:逻辑代码(命令式)
	- App.xaml：应用程序级配置和资源
	- AssemblyInfo.cs:程序集元数据
![[Pasted image 20260722161226.png|359]]
- 结构
	- 解决方案Solution:包含多个项目    
		- .sln:管理项目之间的引用关系和构建设置。
	- 项目Project
		- .csproj，WPF应用程序，编译后生成.exe
	- 依赖项References:显示项目所引用的外部库和NuGet包。
		- .NET SDK的核心引用
	- App.xaml:WPF应用程序的入口文件，等价于WinForms中的Program.cs。
		- App.xaml.cs (App.xaml的代码隐藏文件，包含一个App类，继承自Application。)
			- 应用程序的启动/退出的事件处理；全局异常处理；依赖注入的初始化。
	- AssemblyInfo.cs:程序集级别的元数据属性(版本号;信息;COM可见性设置)
	- MainWindow.xaml:主窗口的界面定义文件(UI和逻辑分离)
		- 用XAML描述窗口的布局、控件、样式等。
		- 默认包含窗口的基本属性和Grid等布局容器。
	- MainWindow.xaml.cs:xaml的代码隐藏文件
		- 包含MainWindow类，继承自Window。
		- 包含窗口的事件处理、与界面交互的业务逻辑；数据绑定相关的代码。

# HelloWPF项目
- 逻辑+UI界面
## MainWindow.xaml
```c#
<Window x:Class="HelloWPF.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
        xmlns:local="clr-namespace:HelloWPF"
        mc:Ignorable="d"
        Title="MainWindow" Height="450" Width="800">
    <Grid>
        <StackPanel VerticalAlignment="Center" HorizontalAlignment="Center">
            <TextBlock x:Name="txtMessage"
                       Text="等待点击..."
                       FontSize="20"
                       Margin="0,0,0,20"/>
            <Button Content="点我"
                    Width="100"
                    Height="40"
                    Click="Button_Click"/> 
        </StackPanel>
    </Grid>
</Window>
```

- x:Name:XAML中控件的名称
- `<Grid></Grid>里放控件


## MainWindow.xaml.cs
- InitializeComponent();//连接XAML和C#的桥梁
- partial:一个类分在两个文件写
- 事件绑定:XAML写Click="方法名"
- 数据修改:.Text

```C#
using System.Text;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Data;
using System.Windows.Documents;
using System.Windows.Input;
using System.Windows.Media;
using System.Windows.Media.Imaging;
using System.Windows.Navigation;
using System.Windows.Shapes;

namespace HelloWPF
{
    /// <summary>
    /// Interaction logic for MainWindow.xaml
    /// </summary>
    public partial class MainWindow : Window //一个类分在两个文件写
    {
        public MainWindow()
        {
            InitializeComponent();//连接XAML和C#的桥梁
        }
        //构造函数 返回值 触发事件的对象；路由事件参数
        private void Button_Click(object sender, RoutedEventArgs e)
        {
            txtMessage.Text = "Helllo,World!";
        }
    }
}
```
