# 3.类型、存储和变量
- C#程序是一组==类型声明==
	- ==命名空间==： 命名空间是一种把相关的类型声明分组并命名的方法。既然程序是一组相关的类型声明，那么通常会把程序声明在你创建的命名空间内部。
- 类型是一种模板
	- ==类型==：创建数据结构的模板，用该模板构造的对象的特征。
		- 名称
		- 保存数据成员的数据结构
		- 一些行为及约束条件
- **实例化类型**
	- 定义:从某个类型/模板创建实际的对象
	- 对象/实例:通过实例化类型而创建的对象被称为类型的对象或类型的实例。
	- 类型/模板:名称、结构、行为
- **数据成员和函数成员**
	- 类型:
		- 简单类型:short、int、long
		- 数组元素:数组
		- 索引
	- 成员:另外一些类型可以包含许多不同类型的数据项。这些类型中的数据项个体
		- 数据:保存了与这个类的对象或作为一个整体的类相关的数据
		- 函数成员:执行类型。定义类型的行为。
	- 定义类型
		- 预定义类型16种=13简单+3非简单(不具备布尔意义)
			- 全小写。
			- 13简单:
				- 11种数值类型；
				- 不同长度的有/无符号整数类型
				- 浮点数float和double
				- decimal，货币计算
				- char:Unicode
				- 布尔:bool
				- ![[Pasted image 20260808190618.png]]
			- 3非简单:string,object,dynamic![[Pasted image 20260808190636.png]]
		- 用户定义类型6种:
			- 类class;结构struct;数组array;枚举enum;委托delegate;接口interface
			- 类class:通过**类型声明**创建，
		- 预定义类型只需要进行实例化；用户定义类型需要两步：声明和实例化
		- ![[Pasted image 20260808191202.png]]
- **栈和堆**"运行时的内存区域"
	- 栈:LIFO后进先出
		- 存储某些类型变量的值、程序当前的执行环境、传递给方法的参数。
	- 堆:存储某类型的数据对象。堆里的内存能以任意顺序存入和移除。
	- **垃圾回收**：CLR的自动GC（Garbage Collector，垃圾收集器）在判断出程序的代码将不会再访问某数据项时，自动清除无主的堆对象。
-  **值类型和引用类型**
	- 数据项的类型存储数据所需要的**内存大小**、组成该类型的**数据成员**、**栈堆**。
	- 存储：
		- 值类型:一段内存，存储数据
		- 引用类型：两段内存，一段存储实际的数据总是位于堆中，一段是一个引用，指向数据在堆中的存放位置。
