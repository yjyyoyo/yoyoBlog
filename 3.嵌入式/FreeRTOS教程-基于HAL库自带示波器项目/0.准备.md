## 2.1 FreeRTOS总图
![[Pasted image 20261102063945.png]]
- 内核移植:模板工程。
- 官网:[www.freertos.org](http://www.freertos.org)
	- FreeRTOS源码(.h和.c)
- FreeRTOS内核结构![[Pasted image 20261102064600.png]]
- 调度器和任务
	- 创建任务:xTaskCreate(vTask1,"Task1",...);
	- 启用调度器:vTaskStartScheduler();
	- 调度算法
		- 带时间片的抢占式
		- 不带时间片的抢占式
		- 协作式
	- vTaskStartScheduler()一般不会退出，除非空闲任务和定时器任务创建失败
- 空闲任务和定时器任务是干嘛的?
	- 空闲任务(备胎):
		- 创建用户任务的数量受单片机内存数量的限制(SRAM)。
	- 定时器:
- 三种中断:Systick,PendSV和SVC(与内核有关)
	- 过去学的:
		- EXTI(外部，捕捉IO引脚的跳变边沿从而产生中断信号)
		- UART(TxE,RxNE,TC和各种错误标志)
		- 定时器
		- ADC
	- FreeRTOS调度器赖以生存的底层硬件，驱动调度器的原动力。
	- Systick:产生系统节拍(计时用的)
	- PendSV:执行后续的任务切换，主力军
	- SVC:启动第一个任务
