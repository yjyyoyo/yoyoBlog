- 核心中枢(系统的基石)
	- 时钟树:脉搏基准，芯片与外设的节拍与工作状态
	- 中断:响应中枢，NVIC/EXTI，打断线性执行流，事件驱动的起点
- 基础交互(感官与执行)
	- GPIO-引脚逻辑:(数字in/out,电气特性，复用映射)
	- TIM定时器-时基与脉冲:(延时、PWM输出控制、输入捕获测量)
	- ADC-模拟转换(模拟信号感知，采样率，硬件触发联动)
- 通信互联与传输(设备间对话与吞吐)
	- UART串口总线:点对点异步通信、调试打印
	- I2C双线总线:多从机寻址、板级传感器交互
	- SPI高速同步:高速全双工，外部存储与屏幕显示
	- DMA硬件搬运:旁路CPU的数据高速传输通道，减小中断开销(外设与内存，内存与内存)
- 驱动分层(软件的抽象)
	- 寄存器底座:硬件地址物理映射，理解底层运作原理
	- HAL封装:标准化API，句柄架构，状态机与回调机制
- 任务协同(多线程与资源调度)
	- FreeRTOS-任务调度:时间片轮转、抢占式优先级、状态流转
	- IPC同步与通信:队列、信号量、事件组、临界区保护
	- 内存管理:堆栈分配、防溢出与内存碎片管理


# 四大多对多(N:M)织节点

- 4大多对多节点
	- 引脚
	- 时序
	- 响应
	- 调度
- 引脚:GPIO与外设的映射，MCU与物理的交互总线
	- 普通IO:
		- 输出模式 ➔ 控制 LED / 驱动继电器。
	    - 输入模式 ➔ 读取按键。
	- 复用AF:
		-  作为通信引脚 ➔ 变为 UART(TX/RX)、I2C(SCL/SDA)、SPI(SCK/MISO/MOSI)。
	    - 作为定时器通道 ➔ 变成 PWM 输出通道（呼吸灯/电机）或 输入捕获引脚（测脉宽/超声波/编码器）。
	- 模拟:
		- 断开内部数字逻辑，直通 **ADC 转换器** 读取模拟电压。
	- 中断源映射:
		- 任意引脚都可以映射到 **EXTI 线路**，产生按键中断或外部触发。
- 时序:TIM定时器的多外设跨界联动，心跳调度
	- TIM和GPIO
		- **TIM ➔ GPIO**：输出比较产生 PWM，精准控制电机和 LED 亮度。
		- **GPIO ➔ TIM**：引脚电平跳变触发输入捕获，测量频率、超声波回波、旋钮编码器角度。
	- **TIM ➔ ADC（硬件级联）**：利用定时器触发事件直接启动 ADC 转换，**完全不需要 CPU 参与**，实现精确的等间隔采样（示波器/音频采集底层核心）。
	-  **TIM ➔ NVIC ➔ FreeRTOS**：定时器溢出中断可以作为 RTOS 的 Tick 心跳源，也能用于软件定时器（Software Timer）。
- 响应:NVIC中断的多源汇聚，顺序线性执行，外设状态的改变汇聚到NVIC
	- 多输入源:
		- EXTI（按键按下/超声波信号到达）。
	    - UART（收到一个字节数据/空闲总线）。
	    - ADC（采样完成 EOC）。
	    - TIM（周期溢出/捕获完成）。
	- 多目标驱动:
		- 裸机下：直接在 ISR（中断服务函数）中改标志位、执行急迫逻辑。
	    - HAL库下：分发到各个 `HAL_xxx_IRQHandler`，再通过弱函数（Callback）回调。
	    - FreeRTOS下：通过 `FromISR` 系列 API，中断直接向 RTOS 释放**二进制信号量**、写入**队列**、置位**事件组**。
- 调度:FreeRTOS与底层；操作系统与硬件外设、内存机制互锁
	- 外设到任务的解耦（异步化）**：
	    - _按键（GPIO/EXTI）_ ➔ 产生中断 ➔ 释放 二进制信号量 ➔ 唤醒 “按键解析任务”。
	    - _传感器采集（ADC/UART）_ ➔ 中断/DMA接收 ➔ 写入 队列 (Queue)➔ 唤醒 “数据处理/万用表计算任务”。
	- 保护临界资源（同步互斥）：
	    - 屏幕（I2C/SPI OLED/LCD）是独占资源，多任务调用时必须引入 互斥锁/守门员任务，否则画面错乱。
	- 内存与堆栈的物理约束：
	    - 每个 Task 的创建都需要从 SRAM 堆（Heap） 中切出一块作为自己的 栈（Stack）。
	    - 局部变量、中断打断时的现场保护（寄存器压栈）都在这一片 SRAM 中，直接制约多任务并发能力。

**“基于 FreeRTOS 的简易示波器/万用表”**
1. **时钟驱动**：RCC 配置时钟树，分配 APB 频率给定时器和 ADC。
2. **硬件触发**：**TIM** 定时产生触发信号 ➔ 自动触发 **ADC** 采样（无需 CPU 轮询）。
3. **数据通道**：ADC 采样完成 ➔ 触发 **NVIC 中断**（或 DMA）。
4. **系统跃迁**：中断服务函数中调用 `xQueueSendFromISR()`，把电压原始值打包送入 **FreeRTOS 队列**。
5. **任务唤醒**：数据处理任务因等待队列而从“阻塞态”变为“就绪态”，被 FreeRTOS 调度器抢占执行，计算有效值。
6. **显示渲染**：处理好的电压字符串通过SPI / I2C 接口刷写到屏幕上，受互斥机制保护防止多个任务抢占屏幕引脚。

**结论**：学习 STM32，就是先学会各个硬件节点的单点操作，再用 **“中断”** 和 **“RTOS”** 穿针引线，最终编织成这张多维的、事件驱动的响应网。
